## Install

```bash
git clone https://github.com/ahmed251095/Wish.git /opt/odoo20/custom_addons/wish
# add /opt/odoo20/custom_addons/wish to addons_path in the Odoo config, then restart
# Apps > Update Apps List > install "MuK Backend Theme"
```

Runs on Odoo 20 **Community**. Backend themes are not supported on Enterprise.
